# 🌈 Projets basés sur SASS

Une collection de projets démontrant l'utilisation des fonctionnalités avancées de **SASS**.

---

### 1. **Solar Planet**
**Description :**  
Reconstitution d'un système solaire animé à l'aide de SASS. Ce projet met en avant l'utilisation des **mixins** et **fonctions** pour gérer les orbites des planètes et des lunes.

- **Technologies utilisées** : HTML, SASS, CSS3
- **Fonctionnalités :**
  - Animations dynamiques des planètes et lunes.
  - Utilisation des **variables** pour centraliser les tailles et couleurs.
  - Gestion des **mixins** pour la réutilisabilité.
- **Dépôt GitHub :** [Lien vers le dépôt](https://github.com/Aerdalis-o1/Sass/Systeme solaire)
