# 🌌 Solar Planet

**Mini projet : Reconstitution d'un système solaire via SASS.**

---

## 📜 Description

Le projet **Solar Planet** est une reconstitution visuelle d'un système solaire conçu à l'aide de **SASS**.  
Il met en avant l'utilisation des fonctionnalités avancées de SASS telles que :  
- Les **fonctions** pour générer des valeurs dynamiques.
- Les **mixins** pour réutiliser du code stylisé.
- Les **variables** pour centraliser les couleurs, dimensions, et paramètres du système solaire.

---

## 🚀 Fonctionnalités

- 🌍 Planètes animées avec des orbites dynamiques.
- 🌞 Soleil central émettant une lumière simulée.
- 🌑 Lunes attachées aux planètes sélectionnées.
- 🌟 Effets visuels pour représenter les étoiles en arrière-plan.

---

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique de la page.  
- **SASS** : Gestion avancée des styles avec :  
  - Variables pour les tailles, couleurs et positions.
  - Mixins pour les animations et orbites.  
  - Fonctions pour calculer les positions dynamiques des planètes.  
- **CSS3** : Génération finale des styles.
